# Contributing to Snippedia

Thanks for taking the time to improve Snippedia. This project is still evolving, so small, focused contributions are especially helpful.

## Development Setup

```sh
npm install
npm run dev
```

Run a production build before opening a pull request:

```sh
npm run build
```

## Pull Request Guidelines

- Keep changes focused on one problem or feature.
- Include a short explanation of what changed and why.
- Avoid committing generated build output, local environment files, or credentials.
- Use existing project patterns before adding new abstractions.
- For UI changes, include screenshots or a short recording when possible.

## Good First Areas

- README screenshots and product walkthrough assets
- Accessibility improvements
- Search result ranking improvements
- Loading and empty states
- Tests for article fetching and normalization

## Reporting Issues

When opening an issue, include:

- What you expected to happen
- What actually happened
- Steps to reproduce
- Browser/device information when relevant
