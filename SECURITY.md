# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security reports.

If you discover a vulnerability, leaked credential, exposed private file, or unsafe deployment configuration, contact the maintainer privately through GitHub profile contact information or repository discussions if enabled.

Please include:

- A clear description of the issue
- Steps to reproduce when possible
- Any affected URLs, files, or endpoints
- Suggested remediation if you have one

## Sensitive Data

Do not commit real credentials, API keys, database passwords, access tokens, or private environment files. Use `.env.example` files for documentation and keep real `.env` files local.

## Supported Version

Snippedia is currently maintained from the `main` branch.
